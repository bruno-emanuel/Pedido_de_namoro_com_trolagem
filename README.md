

#Pedido de Namoro (Trolagem)


Um site de pedido de namoro feito como brincadeira.
O botão "Sim" foge e o botão "Não" revela que tudo era apenas uma trolagem.

Objetivo

Este projeto tem como finalidade ser uma brincadeira leve para compartilhar com amigos ou conhecidos.

Como usar
Baixe o projeto (ZIP)
Extraia os arquivos
Abra o arquivo index.html no navegador
Estrutura do projeto
pedido_namoro_trolagem/
│
├── index.html   # Estrutura da página
├── style.css    # Estilo visual
└── script.js    # Lógica da interação
Funcionamento
Botão "Sim":
Se move ao aproximar o cursor do mouse
Botão "Não":
Pode ser clicado normalmente
Exibe a mensagem final informando que é uma brincadeira
Personalização
Mensagem final

No arquivo script.js, localize:

alert("Era brincadeira");

Altere para qualquer mensagem desejada.

Texto principal

No arquivo index.html, edite:

<h1>Quer namorar comigo?</h1>
Estilo visual

No arquivo style.css, você pode modificar:

Cores
Fontes
Tamanhos e layout
Aviso

Utilize com bom senso. Dependendo da pessoa, a reação pode não ser positiva.

Tecnologias utilizadas
HTML5
CSS3
JavaScript
Autor

Projeto criado para fins de entretenimento.
